# LLM 대화 플러그인 테스트 가이드

이 폴더에는 LLM 대화 플러그인을 테스트하기 위한 에셋과 가이드가 포함되어 있습니다.

## 1. 플러그인 활성화하기

1. 언리얼 에디터를 엽니다.
2. Edit > Plugins 메뉴를 선택합니다.
3. "LLM Dialogue Plugin"을 검색합니다.
4. 해당 플러그인을 활성화하고 에디터를 재시작합니다.

## 2. 테스트 에셋 설정하기

다음 블루프린트들을 생성해야 합니다:

### 2.1 대화 UI 위젯 (WBP_DialogueUI)

UI/WBP_DialogueUI.uc 파일에 있는 가이드를 따라 위젯 블루프린트를 생성합니다.

### 2.2 NPC 블루프린트 (BP_TestNPC)

Blueprints/BP_TestNPC.uc 파일에 있는 가이드를 따라 NPC 블루프린트를 생성합니다. 중요한 점은:
- LLMDialogueComponent를 추가합니다.
- 유효한 OpenAI API 키를 설정합니다.
- 대화 시스템을 설정합니다.

### 2.3 플레이어 블루프린트 (BP_InteractivePlayer)

Blueprints/BP_InteractivePlayer.uc 파일에 있는 가이드를 따라 상호작용 가능한 플레이어 블루프린트를 생성합니다.

## 3. 테스트 맵 구성하기

Maps/TestMap_Guide.txt 파일에 있는 가이드를 따라 테스트 맵을 구성합니다.

## 4. API 키 설정하기

이 플러그인은 OpenAI API와 통신하기 위해 유효한 API 키가 필요합니다:

1. OpenAI 웹사이트에서 API 키를 발급받습니다.
2. BP_TestNPC의 DialogueComponent 속성에서 API Key 필드에 키를 입력합니다.

## 5. 테스트 실행하기

1. 맵을 저장합니다.
2. Play 버튼을 클릭하여 에디터에서 테스트합니다.
3. 플레이어를 NPC에 접근시킵니다.
4. 상호작용 키(E 키 기본)를 눌러 대화 UI를 활성화합니다.
5. 메시지를 입력하고 전송 버튼을 클릭합니다.
6. NPC의 응답을 확인합니다.

## 주의 사항

- 이 플러그인은 인터넷 연결이 필요합니다.
- OpenAI API 사용에는 비용이 발생할 수 있습니다.
- 대화 상태 머신은 다음 네 가지 상태로 구성됩니다: Greeting, Information, QuestOffer, Goodbye
- NPC 응답에 <NEXT_STATE:상태명> 태그가 포함되면 자동으로 상태가 전환됩니다.

## 확장 및 개선

플러그인을 확장하고 개선하는 방법:

- 다양한 LLM API 지원 추가 (Claude, Gemini 등)
- 대화 로깅 및 저장 기능 구현
- 음성 출력 통합
- 다양한 대화 UI 스타일 추가
- 퀘스트 시스템과 연동
- 플레이어 선택지 기반 대화 옵션 추가

## 문제 해결

- API 키가 올바르게 설정되었는지 확인합니다.
- 인터넷 연결을 확인합니다.
- 출력 로그에서 오류 메시지를 확인합니다.
- 대화 상태 전환이 제대로 작동하지 않는 경우, 템플릿에 적절한 태그가 포함되어 있는지 확인합니다.
