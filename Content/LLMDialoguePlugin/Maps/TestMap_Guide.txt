# LLM 대화 플러그인 테스트 맵 구성 가이드

이 가이드는 LLM 대화 플러그인을 테스트하기 위한 맵 구성 방법을 설명합니다.

## 1. 테스트 맵 생성하기

1. 콘텐츠 브라우저에서 LLMDialoguePlugin/Maps 폴더에 우클릭합니다.
2. Level > 빈 레벨을 선택합니다.
3. 맵 이름을 "TestMap"으로 저장합니다.

## 2. 기본 환경 구성하기

1. 바닥 추가:
   - Modes 패널에서 Basic 카테고리 선택
   - Plane 드래그하여 배치 (크기: 10000 x 10000)
   - 바닥으로 사용할 머티리얼 적용

2. 광원 추가:
   - Modes 패널에서 Lights 카테고리 선택
   - Directional Light 추가 및 적절한 위치에 배치
   - 디테일 패널에서 강도와 색상 조정

3. 스카이 스피어 및 대기 조명 추가:
   - Modes 패널에서 Visual Effects 카테고리 선택
   - Sky Atmosphere 추가
   - 디테일 패널에서 원하는 대로 조정

## 3. NPC 배치하기

1. 콘텐츠 브라우저에서 LLMDialoguePlugin/Blueprints/BP_TestNPC를 찾습니다.
2. 맵에 드래그하여 배치합니다.
3. 필요한 경우 NPC 위치 조정

## 4. 플레이어 시작 위치 설정하기

1. Modes 패널에서 Basic 카테고리 선택
2. Player Start 찾아서 맵에 배치
3. NPC 근처에 위치시키기

## 5. 플레이어 캐릭터 구성하기

1. 프로젝트 세팅(Edit > Project Settings)을 엽니다.
2. Maps & Modes 카테고리로 이동:
   - Default Game Mode: Game Mode Base 설정
   - Default Pawn Class: Third Person Character 또는 원하는 캐릭터 클래스 설정

## 6. 상호작용 입력 설정하기

1. 프로젝트 세팅에서 Input 카테고리로 이동
2. Action Mappings 추가:
   - 이름: "Interact"
   - 키: E 키 또는 원하는 키

## 7. 테스트 맵 플레이하기

1. 저장: 모든 변경 사항 저장 (Ctrl+S)
2. 재생: 에디터에서 Play 버튼 클릭
3. 플레이어를 NPC에 접근시켜 E 키(또는 설정한 상호작용 키)를 눌러 대화 UI 활성화
4. 대화 입력 박스에 메시지 입력 후 전송 버튼 클릭
5. NPC의 응답 확인

## 주의 사항

- 플러그인이 정상적으로 작동하려면 유효한 OpenAI API 키가 필요합니다.
- API 키는 BP_TestNPC의 DialogueComponent 디테일 패널에서 설정해야 합니다.
- 인터넷 연결이 필요하며, API 호출에는 비용이 발생할 수 있습니다.
- 패키징된 게임에서는 API 키가 노출될 수 있으므로 개발 단계에서만 사용하거나 적절한 보안 조치를 취해야 합니다.

## 추가 개선 사항

- NPC에 애니메이션 추가 (대화 중 제스처 등)
- NPC 근처에 접근했을 때 자동으로 대화 UI 표시
- 대화 내용에 따라 퀘스트 시스템 연동
- 다양한 NPC 추가하여 각각 다른 성격과 대화 스타일 부여
